DreamMaker Scheduler 学习课程

面向对象：新入职同事、需要了解 Scheduler 系统的开发人员

目标：从零建立对 DreamMaker Scheduler 微服务集群的整体认知，理解任务从提交到完成的全链路，掌握核心调度和高可用机制。

总时长：约 2 小时

建议顺序：S001 → S002 → S003，每节课都以前一节为前置知识。

课程目录

S001 · DreamMaker Scheduler 整体架构总览

~35 分钟 · ★★★☆☆
一句话了解系统全貌，掌握五层架构的职责边界、三大核心组件（app-gateway / worker-scheduler / worker-sidecar）的分工，以及一个任务从提交到完成的完整生命周期。

S002 · 任务调度全链路与 Redis 队列设计

~45 分钟 · ★★★☆☆
深入任务状态机、Action 编排模式、Redis ZSet 队列的乐观抢占机制、优先级加权调度、用户并发控制（CAS + etcd Watch）、Kafka 事件广播，以及端到端的数据流。

S003 · Worker 调度与高可用

~40 分钟 · ★★★★☆
K8s LeaseLock Leader 选举、etcd Worker/Task 注册与 Lease 机制、心跳与故障检测、Worker 生命周期状态机、Sidecar 优雅关闭、自定义 Autoscaler 扩缩容、实例启动时的数据恢复。

技术栈概览

技术在 Scheduler 中的角色
Go + dmfr微服务框架，统一 HTTP Server/Client、日志、错误码
Redis (ZSet)任务队列 + 乐观抢占 + 状态缓存 + 分布式锁
MongoDB任务记录中心（AppRecord），长期存储参数、状态、结果
etcdWorker/Task 运行态注册，Lease 自动清理，Watch 事件驱动
Kafka任务结果通知下游（监控、统计、告警）
K8s + Istio服务发现、流量路由、统一鉴权、HPA 自动扩缩
Hertz / FiberHTTP 框架（新代码 Hertz，老代码 Fiber）

阅读建议

  • 带着"一个任务从用户点击到返回结果经过了哪些组件"这条主线来读
  • 每节课的代码片段对应仓库 dreammaker-scheduler 中的真实路径，可以对照阅读
  • 遇到不清楚的 dmfr 用法，查仓库根下的 AGENTS.md
  • 如果需要了解 Monet Agent 端的架构，参考同级目录下的 Monet 课程
