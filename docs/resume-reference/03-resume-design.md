## 八、避坑清单（来自简历评论）

| 坑 | 正确做法 |
|----|---------|
| 技术名词堆砌 | 每个技术名词后面跟"用它解决了什么问题" |
| 只写做了什么 | 写"用 XX 技术解决了 XX 问题，结果 XX" |
| 套模板项目 | 加点自己的小巧思，做出差异化 |
| 没有量化指标 | 必须有数字：成功率 XX%、延迟 XXms |
| 项目没背景 | 开头一句话交代业务场景和规模 |
| 简历太满 | 适当留白，重点加粗，一页为佳 |
| 关键词缺失 | 编程语言必须出现在专业技能栏 |
| 后端项目没后端技术 | DM 项目里把 Go、分布式、高并发写清楚 |
