# 用户背景

## 基本信息

- **角色**：AI 应用开发实习生
- **入职时技术栈**：纯 Python + 纯 Agent（本地 demo 级别）
- **缺乏经验的方向**：后端工程（Go / 微服务 / 线上部署）、团队协作流程（Git 分支模型、Code Review、Spec 驱动开发）

## 学习目标

1. **理解 DreamMaker 整体架构**：搞清楚 scheduler / gateway / monet-agent 三个仓库各自干什么、怎么串起来。
2. **具备独立开发能力**：能独立完成一个从 spec → 编码 → 测试 → MR 的完整闭环。
3. **简历产出**：把实习期间参与的 Agent 和后端 项目经验（架构理解、feature 开发、性能优化等）写进简历，为秋招增加竞争力。

## 协作偏好

- 中文沟通，技术术语保留英文原文。
- 解释偏新手友好：先讲业务背景再讲代码细节。
- 遇到不确定的地方宁可多问一句，不要默默假设。
- 关注"这个东西怎么写进简历"——学到的东西要能用一句话概括出价值。
